# GitHub User App (Android / Kotlin)

GitHub REST APIを利用してユーザー情報の閲覧、高度な検索、使用言語の視覚的グラフ化を行うJetpack Compose製のAndroidアプリケーションです。

---

## 📖 プロジェクトの概要

本アプリは、GitHub上のユーザー情報を探索・分析するためのモダンなAndroidアプリケーションです。
Material 3ガイドラインに準拠した美しいデザインと最新のJetpack Composeアーキテクチャを採用し、最終コミット日時によるアクティビティ順表示、マルチ言語タグ検索、カスタムCanvas描画による使用言語比率のドーナツ円グラフ表示など、直感的で滑らかな操作体験を提供します。

## ✨ 主な機能の説明

### 1. ユーザー一覧表示
- **アクティビティ順ソート**: 各ユーザーの公開リポジトリ情報から最終コミット（プッシュ）日時を取得し、アクティブなユーザー順に一覧表示します。
- **主要言語バッジ**: 各ユーザーカードの右側に、頻繁に使用している主要プログラミング言語（上位最大2個）をバッジとして表示します。
- **最終コミット日時の表示**: ユーザー名の下部に直近のコミット日（例: `2026/09/04`）を分かりやすく表示します。

### 2. モーダル式高度検索フォーム
- **スムーズなモーダルボトムシート**: ボタン押下で画面下部から広がるモーダル形式の検索シートを採用。
- **名前・アカウント名検索**: リアルタイムキーボード連携による名前キーワード検索。
- **複数言語のタグ選択**:
  - `Kotlin`, `Swift`, `TypeScript`, `Python` などのワンタップ「主要言語クイック選択」チップ。
  - 自由入力欄から任意のプログラミング言語を追加できる機能。
- **検索条件バナーとタップ再編集**: 検索フィルタ適用時は画面上部にアクティブな条件がバナー表示され、バナー全体をタップすることでいつでも検索モーダルを開いて条件を再編集できます。

### 3. 無限スクロール ＆ プルダウン更新 (Pagination & Pull-to-Refresh)
- **1回あたり20件取得**: 通信量の最適化およびレスポンス高速化のため、取得単位を20件に調整。
- **プルダウン更新 (Pull-to-Refresh)**: 画面最上部で下にスワイプすることで、いつでも最新の20件データを再取得・更新できます。
- **無限スクロール (Pagination)**: リストの最下部付近にスクロールすると、自動で次の20件（通常時: `since` パラメータ、検索時: `page` パラメータ）を追加読み込みします。

### 4. ユーザー詳細画面 ＆ 言語使用割合グラフ
- **プロフィール詳細**: アバター画像、氏名、Bio（自己紹介）、居住地、フォロワー数、フォロー数、公開リポジトリ数、GitHub登録日を表示。
- **ドーナツ型円グラフ (Custom Canvas)**: ユーザーの全公開リポジトリを解析し、プログラミング言語の利用割合（%）を計算。Jetpack Compose の `Canvas` (`drawArc`) を使用して独自のインタラクティブな円グラフを描画・可視化します。

### 5. テスト用サンプルデータモード
- APIレート制限（HTTP 403）発生時やオフライン開発時でも動作を確認できるよう、独立したダミーデータモジュール (`SampleUserData`) を搭載。

## 🌟 追加実装した機能一覧 (Additional Features)

基本仕様要件に加え、ユーザー体験（UX）向上および実用性・堅牢性の確保のために独自に追加実装した機能の一覧です。

### 📱 ユーザー一覧
- **高度なマルチ検索機能**: ユーザー名キーワード検索 ＋ プログラミング言語の複数タグ指定（主要言語クイック選択 ＋ 任意言語の自由入力追加）。
- **タップ編集対応の検索条件バナー**: 現在適用中の検索条件を画面上部にバナー表示し、バナー全体をタップすることでいつでもモーダル検索画面を再開・編集可能。
- **最終プッシュ日でのソート**: 各ユーザーの公開リポジトリの最終コミット・プッシュ日時を非同期並列で自動抽出し、アクティブな最新順に並び替え。
- **主要使用言語バッジ**: 各ユーザーカードの右側に頻度の高い上位2言語を自動集計してバッジ表示。
- **画面最上部スワイプでのデータ更新 (Pull-to-Refresh)**: 画面最上部で下にスワイプすることで、最新データを即座に再ロード。
- **データ取得20件制限**: パフォーマンスおよび通信量最適化のため、1回の取得上限を20件に制限。
- **画面最下部での自動追加更新 (無限スクロール / Pagination)**: リスト最下部への到達を自動検知し、次の20件を追加読み込み。

### 👤 ユーザー詳細
- **言語使用情報のドーナツ円グラフ表示**: ユーザーの全公開リポジトリ言語を解析し、Jetpack Compose `Canvas` (`drawArc`) による独自開発のドーナツ型円グラフとパーセンテージ表示で視覚的に可視化。
- **GitHub URLタップでの外部ブラウザ起動**: ユーザー詳細画面のプロフィールURLカードをタップすることで、Android標準のIntent経由で外部ブラウザ（Chrome等）を開きWebプロフィールページを表示。

## ⚙️ 開発環境・ビルド方法

### 前提条件
- **Android Studio**: Ladybug 以降
- **JDK**: 17 / 21
- **Target SDK**: Android API Level 36 (Android 16)
- **Min SDK**: Android API Level 24 (Android 7.0)

### ビルド手順
```bash
# リポジトリのクローン
git clone <repository-url>
cd GitHub_user_app

# デバッグ用APKのビルド
./gradlew assembleDebug
```
